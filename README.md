Sistema de Control de Rescate y Adopción Animal

Descripción del proyecto

Este proyecto académico propone el diseño de un sistema informático para gestionar el rescate, la atención médica y la adopción de animales.

El sistema permitirá registrar animales rescatados, clasificarlos por especie, asignar voluntarios o veterinarios y actualizar el estado de cada caso.

Objetivo

Diseñar una arquitectura lógica que facilite la organización y el seguimiento de los casos de rescate y adopción animal.

Actores principales

Ciudadano o reportante.

Voluntario o veterinario.

Administrador del refugio.

Estados de los casos

Reportado.

Rescatado.

En tratamiento.

Disponible para adopción.

Adoptado.

Herramientas utilizadas

GitHub para almacenar y controlar las versiones del proyecto.

Draw.io para elaborar los diagramas UML.

Contenido del proyecto

En este repositorio se documentarán el análisis de requisitos, los diagramas UML, la arquitectura del sistema y los patrones de diseño propuestos.
